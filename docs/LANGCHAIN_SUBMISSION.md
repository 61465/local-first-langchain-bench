# LangChain submission plan

**Problem:** `langchain-ai/langchain` Discussions is restricted to `Announcements`
category only (member-posted). Community cannot start new discussions.

**Plan:**
1. GitHub repo published: https://github.com/61465/local-first-langchain-bench (DONE)
2. Open an Issue on `langchain-ai/langchain` with the RFC headline + link to this repo
3. Issue type: `feature request` or standard issue
4. Keep issue body SHORT (maintainers skim):
   - 3-line summary
   - Headline numbers (HSTC 49.2% reduction, Wilcoxon p=7.96e-16, 86/86 direction-stable)
   - Link to full RFC in repo
   - Request: "Is this a direction LangChain is interested in? If yes, happy to open a PR with the compressor as `langchain.compress.HybridCompressor` wrapper."

Issue draft is at `docs/LANGCHAIN_ISSUE_DRAFT.md`.
